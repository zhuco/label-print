# v0.1.1

发布日期：2026-04-06

## 最近更新概览

- 完成标签编辑器近期功能整合，补齐元素预设、文本样式与标尺相关能力。
- 优化首页与最近模板入口，增强桌面端默认启动体验。
- 完善 Tauri 命令与前端 IPC 协作流程，提升模板与打印链路稳定性。
- 新增/补充多组单元测试与集成测试，覆盖编辑器核心逻辑与打印提交流程。
- 应用品牌名称与安装器中文化细节同步更新。

## 功能与体验改进

- 编辑器侧：
  - 补充文本样式、条码文本样式、视觉预设与标尺相关能力。
  - 优化左侧元素面板、右侧属性面板与画布交互流程。
  - 改进新建标签与提交打印弹窗的可用性。
- 首页侧：
  - 默认进入首页，强化最近标签/模板入口与缩略图体验。
- 后端与集成：
  - 扩展 Tauri 命令模块与仓储能力，优化模板与打印任务调用链。
  - 增补 IPC 层能力并补充对应测试。

## 构建与发布改进

- 安装脚本继续强化中文化处理与图标同步流程。
- 项目版本统一升级至 `0.1.1`（前端包、Rust 包、Tauri 配置与安装包命名同步）。

## 仓库清理

- 删除无用临时日志与本地运行记录文件。
- 删除无效样例/副本文档（`.lpt`、`.ddl` 类本地产物）。
- 更新 `.gitignore`，避免本地产物再次污染仓库。

## 支持平台

- Windows x64

## 已知限制

- 当前仍以系统驱动打印链路为主，暂未提供 ZPL/TSPL 原生后端。
- 暂不包含云端同步与多用户协作能力。
