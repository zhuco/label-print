# v0.1.5

发布日期：2026-08-23

## 本次更新概览

- 调整热敏打印图像处理流程，文字与条码下方数字在不同打印机分辨率上的输出更稳定。
- 修复营养成分表矩形框左侧边线可能在预览或打印捕获中缺失的问题。
- 修复编辑器左侧元素、中间画布和右侧属性面板会随选中元素内容改变整体高度的问题。
- 补充 Windows 7 构建脚本的 SHA-256 兼容计算逻辑。

## 打印与预览

- 打印前会按打印机的实际点阵尺寸生成单色位图，再交给系统驱动输出，避免小号中文笔画与条码数字经过多次缩放后变淡或变形。
- 文本与条码数字的适配改为等比缩小字体与字间距，不再使用横向拉伸，保留字形比例。
- 矩形和圆角矩形框线改为在元素边界内绘制，避免 SVG 描边贴边时在缩放或捕获阶段裁掉左侧线条。

## 编辑器体验

- 编辑器工作区固定占用窗口剩余高度；元素、画布和属性面板保持等高，并由各自区域滚动。
- 当侧栏开关条隐藏时，工作区仍固定落在剩余高度行，切换文字、条码、图形等元素不会改变三栏整体高度。

## 构建与发布

- 项目版本统一升级至 `0.1.5`，同步更新桌面端、Tauri/Rust 包、内部前端包和应用版本图标。
- Windows 7 构建脚本在缺少 `Get-FileHash` 的环境中会回退到 `certutil` 计算 SHA-256。

## 测试与验证

- 前端 Vitest：216 项测试通过。
- Rust：15 项测试通过。
- 前端生产构建与 TypeScript 检查通过。

## 已知限制

- 当前打印后端仍依赖 Windows 系统驱动，尚未提供 ZPL、TSPL 等原生打印指令后端。
- 真实热敏打印机、纸张、碳带、驱动和校准设置仍会影响最终效果；发布前应在目标机型上进行实际打印与条码扫描验收。
