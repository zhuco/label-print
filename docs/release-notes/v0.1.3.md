# v0.1.3

发布日期：2026-04-14

## 本次更新概览
- 新增图形/图标高级视觉样式能力，支持更细粒度的描边、透明度、虚线和填充规则调节。
- 改进图形与图标元素默认尺寸策略，按预设真实宽高比自动适配，减少插入后手动修形。
- 优化模板保存与最近记录交互，避免历史记录中出现同名冲突带来的误保存。
- 整理数据导入包导出结构，并补充构建产物清理脚本，方便开发期维护。

## 功能与体验改进
- 编辑器视觉样式：
  - 右侧属性面板新增视觉样式预设，可快速切换工业默认、警示虚线、流程点线和重轮廓等风格。
  - 新增描边宽度、描边颜色、填充颜色、描边/填充透明度、线帽、线连接、虚线数组、虚线偏移、斜接限制和填充规则控制项。
  - 所有视觉样式输入在状态层统一做边界归一化，避免异常值写入元素数据。
- 图形与图标布局：
  - 新增预设宽高比适配逻辑，插入图形/图标时自动按真实比例落到画布。
  - 最近标签缩略图与画布表现同步增强，更贴近最终样式效果。
- 模板保存流程：
  - 保存模板前会检查最近记录中的同名冲突，避免误覆盖不同来源的模板。
  - 首页最近记录菜单交互进一步细化，减少菜单误关闭。
- 数据导入与工程脚本：
  - `@label/data-import` 增加子路径导出，支持按 `csv`、`excel`、`preview` 分模块引入。
  - 新增 `clean:build` 命令与 [clean-build.ps1](F:\label-print\scripts\clean-build.ps1)，可一键清理桌面端构建与测试产物。

## 测试与验证
- 补充视觉样式归一化、元素比例适配、打印提交弹窗和应用壳层相关测试。
- 持续覆盖编辑器状态、视觉预设与保存流程的关键回归场景。

## 构建与发布
- 项目版本统一升级至 `0.1.3`，同步更新前端包、Rust 包、Tauri 配置和版本展示资源。

## 支持平台
- Windows x64

## 已知限制
- 当前打印后端仍以 Windows 系统驱动链路为主，暂未提供 ZPL/TSPL 原生后端。
- 高级视觉样式主要面向图形和图标元素，复杂模板仍可能需要结合实际打印效果微调。
