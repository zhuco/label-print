# v0.1.0

## Highlights

- Desktop label editor shell with element palette, canvas, and inspector
- CSV/Excel import package with preview and missing-column checks
- Rust label core with variable expansion and queue state machine
- SQLite repositories + Tauri commands for templates and jobs
- Calibration page and job logs page
- Responsive baseline validated via Playwright (1366x768 + 1920x1080)

## Supported Platforms

- Windows x64

## Known Limitations

- Driver-based printing only (no ZPL/TSPL native backend yet)
- No cloud sync / multi-user collaboration
