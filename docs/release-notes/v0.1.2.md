# v0.1.2

发布日期：2026-04-13

## 本次更新概览
- 新增图片识别导入链路，支持通过本地 OCR 与条码识别结果快速生成标签元素。
- 扩展编辑器预设能力，补充行业模板、自定义图形保存/复用，以及更多图形与图标入口。
- 优化最近标签、打印链路和本地数据路径，提升桌面端启动与日常操作体验。
- 继续补充单元测试与 IPC 测试，覆盖识别导入、行业模板、打印缓存与编辑器状态逻辑。

## 功能与体验改进
- 识别导入：
  - 新增原生识别命令与 OCR sidecar，结合本地 OCR、条码和二维码识别结果生成画布元素。
  - 增加识别结果到标签元素的转换逻辑，自动按标签尺寸映射文本、条码、二维码、图形和图标。
- 编辑器增强：
  - 左侧面板新增行业模板、自定义图形等选择入口，补充更多图标/图形资源。
  - 支持将当前选区保存为自定义图形，并在后续标签中快速复用。
  - 新增食品信息加营养成分等行业模板，补足常见业务场景起步布局。
  - 改进条码元素尺寸约束、文本样式输入边界和画布交互细节。
- 首页与最近记录：
  - 最近标签支持右键删除记录，首页入口操作更顺手。
  - 保存流程补强对不同文件来源的处理，减少关闭标签页时的中断感。
- 打印与桌面端能力：
  - 增加软件默认打印机记忆能力，并优化系统打印机缓存与预热策略。
  - 打印相关 PowerShell 调用改为隐藏窗口执行，减少后台闪窗干扰。
  - 数据库路径迁移到用户数据目录，并保留旧库自动迁移逻辑。

## 构建与发布
- 项目版本统一升级至 `0.1.2`，同步更新前端包、Rust 包、Tauri 配置和相关版本资源。
- 安装包构建脚本继续沿用中文化 WiX 处理、图标同步和离线 WebView2 配置能力。

## 仓库清理
- 删除本地预览日志、临时数据库、DDL 导出文件以及测试/构建生成目录，减少仓库噪音。
- 保留正式文档资源与源码文件，不影响当前功能改动的提交范围。

## 支持平台
- Windows x64

## 已知限制
- 当前打印后端仍以 Windows 系统驱动链路为主，暂未提供 ZPL/TSPL 原生后端。
- 识别导入更适合结构清晰的标签图片，复杂背景或低清晰度图片仍可能需要手动微调。
