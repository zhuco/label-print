# 标签编辑打印软件（桌面单机）设计文档

- 日期：2026-04-02
- 版本：v1.0（MVP 设计冻结稿）
- 状态：已完成需求收敛，待实现计划

## 1. 项目目标

本项目构建一个仅面向本地电脑运行的标签编辑打印软件（非 Web 用户端），满足通用标签设计与批量打印需求。首发目标：

1. 提供可视化标签编辑能力（所见即所得）。
2. 支持 Excel/CSV 可变数据批量打印。
3. 在 Windows x64 环境下稳定调用系统驱动完成热敏打印。
4. 提供可追溯的打印任务日志与失败恢复机制。
5. UI 风格专业、大气，且在多分辨率/多缩放下可用。

## 2. 约束与边界

### 2.1 已确认约束

1. 平台：仅 `Windows x64`。
2. 技术路线：`Tauri + React + TypeScript + Rust`。
3. 打印链路：首发仅 `Windows 驱动统一打印`（暂不做 ZPL/TSPL 直出）。
4. 产品定位：通用可配置场景（不绑定单一行业）。
5. 设备方向：优先热敏标签打印机。
6. 尺寸策略：内置常用尺寸库 + 用户自定义。
7. 数据能力：首发必须支持 Excel/CSV 批量打印。
8. 开源许可：`MIT`。
9. 设计重点：优先适配多种电脑屏幕分辨率与系统缩放。

### 2.2 非目标（MVP 暂不实现）

1. 云端账号、云同步、远程任务下发。
2. 多人协作与权限系统。
3. macOS/Linux 适配。
4. 浏览器端在线编辑。
5. 打印机原生命令（ZPL/TSPL）直出。

## 3. 系统架构

### 3.1 分层结构

1. UI 层（React + TypeScript）
   - 标签编辑器（画布、图层、属性面板）
   - 数据导入与字段映射界面
   - 打印任务控制台（队列、状态、重试）
   - 打印机设置与校准页面

2. 应用壳层（Tauri）
   - 系统窗口与菜单
   - 本地文件系统访问
   - 调用 Rust 核心能力
   - 桌面打包发布

3. 领域核心层（Rust）
   - 模板解析与版本迁移
   - 变量替换与渲染模型生成
   - 打印任务编排（队列、暂停、继续、取消）
   - 打印执行状态回写

4. 持久化层（SQLite）
   - 模板、模板版本
   - 打印机配置、尺寸预设
   - 打印任务历史、错误日志

### 3.2 可扩展接口（为开源预留）

1. `ElementProvider`：扩展编辑器元素能力。
2. `DataProvider`：扩展数据来源（未来数据库/接口）。
3. `PrintBackend`：扩展打印后端（未来接入 ZPL/TSPL）。

## 4. 功能设计（MVP）

### 4.1 模板编辑

1. 新建模板：从尺寸库选择或自定义尺寸。
2. 元素支持：文本、条码、二维码、图片、矩形、线条。
3. 编辑交互：拖拽、缩放、多选、对齐线、吸附、分布。
4. 图层控制：上移/下移、锁定、隐藏。
5. 画布能力：标尺、网格、缩放（25%~400%）、适应窗口。
6. 快捷能力：撤销/重做、复制粘贴、键盘微调。

### 4.2 数据导入与字段绑定

1. 导入格式：CSV、Excel（.xlsx）。
2. 字段识别：自动读取列名并生成字段列表。
3. 绑定方式：模板变量（如 `${sku}`）映射到数据列。
4. 数据预览：展示前 N 条样本并高亮缺失字段。
5. 规则处理：空值策略（空串/默认值/跳过）。

### 4.3 打印执行

1. 打印机选择：读取系统可用打印机列表。
2. 参数设置：份数、速度（若驱动支持）、方向、偏移。
3. 队列模型：任务入队、暂停、继续、取消。
4. 失败机制：失败条目重试、跳过、失败即停可配置。
5. 预检：打印前检查模板字段、打印机状态、尺寸匹配。

### 4.4 校准与日志

1. 校准页：X/Y 偏移、缩放微调、测试打印。
2. 历史页：任务时间、模板名、成功/失败数、耗时。
3. 问题定位：记录失败错误码、错误描述、上下文参数。
4. 诊断导出：一键导出日志文件，便于社区 issue 反馈。

## 5. UI/UX 设计规范

### 5.1 布局策略

1. 标准布局：左元素库 + 中央画布 + 右属性栏 + 顶部工具栏。
2. 小屏策略（1366x768）：左右栏可折叠，优先保证画布工作区。
3. 大屏策略（>=1920）：展示更多高级参数与任务信息。

### 5.2 视觉规范

1. 风格关键词：工业专业感、清晰层级、低噪信息。
2. 字体建议：`Noto Sans SC` / `HarmonyOS Sans SC`。
3. 色彩策略：中性底色 + 单强调色（蓝/青），控制视觉负担。
4. 状态反馈：保存、导入、打印、失败都必须有明确反馈。

### 5.3 多分辨率与缩放适配

1. 分辨率覆盖：1366x768、1920x1080、2K、4K。
2. 缩放覆盖：100% / 125% / 150% / 200%。
3. 交互底线：关键按钮不被折叠到不可点击；文本不重叠、不截断关键字段。
4. 降级规则：空间不足时优先隐藏次要信息，不牺牲核心流程。

## 6. 核心数据流

打印全链路：

1. 加载模板与尺寸配置。
2. 导入数据并映射字段。
3. 打印前预检（字段完整性、打印机可用性、尺寸合法性）。
4. 按行渲染打印页模型（流式，不一次性全量加载）。
5. 写入任务队列并执行。
6. 收集每条结果并写回任务日志。
7. 失败条目按策略处理（重试/跳过/停止）。

## 7. 错误处理与可靠性

1. 可预见错误前置拦截：缺字段、无打印机、尺寸不匹配。
2. 运行时异常隔离：单任务失败不导致应用崩溃。
3. 批量容错：支持失败不中断，保证大批量可持续执行。
4. 日志分级：`INFO/WARN/ERROR`。
5. 可恢复性：所有失败任务保留“重试”与“查看详情”入口。

## 8. 测试策略

### 8.1 单元测试

1. 模板解析与版本迁移。
2. 变量替换与字段缺失处理。
3. 尺寸换算与坐标渲染逻辑。
4. 队列状态机（暂停/继续/取消）。

### 8.2 集成测试

1. CSV/Excel 导入到字段映射全链路。
2. 渲染输出一致性（相同输入输出一致）。
3. 打印参数组装与后端调用接口稳定性。

### 8.3 E2E 测试

1. 新建模板 -> 放置元素 -> 保存。
2. 导入数据 -> 字段映射 -> 批量打印。
3. 人为制造失败 -> 日志记录 -> 重试成功。

### 8.4 兼容性测试

1. 分辨率：1366x768、1920x1080、2K、4K。
2. 缩放：100%/125%/150%/200%。
3. 打印机：至少 2 款主流热敏机型（203dpi 与 300dpi）。

## 9. 验收标准（MVP）

1. 批量 1000 条任务可稳定执行，成功率达到预设基线（在测试环境定义具体阈值）。
2. 常见标签尺寸可通过校准达到可用打印位置精度。
3. 首次打开到打印首张标签流程清晰可达（新手可完成）。
4. 打印失败可追溯、可重试、可导出日志。
5. 多分辨率与缩放场景无阻断性 UI 问题。

## 10. 里程碑（8 周）

1. 第 1 周：项目骨架、主题系统、配置页、数据库基础。
2. 第 2-3 周：编辑器 MVP（画布、元素、模板保存加载）。
3. 第 4 周：CSV/Excel 导入、字段映射、预览。
4. 第 5 周：打印任务队列、执行状态与重试。
5. 第 6 周：校准工具、设备配置、尺寸预设。
6. 第 7 周：E2E 与适配测试、性能优化、日志完善。
7. 第 8 周：开源文档完善与首版发布。

## 11. 开源治理与仓库规范

1. 许可证：`MIT`。
2. 基础文件：`README`、`CONTRIBUTING`、`CODE_OF_CONDUCT`。
3. Issue 模板：Bug/Feature 两类，包含环境与日志字段。
4. 发布说明：明确已支持机型/已知限制/升级路径。

## 12. 风险与应对

1. 打印机差异风险
   - 应对：建立机型适配矩阵，优先覆盖高频型号。
2. 定位偏移风险
   - 应对：标准化校准流程与可复用参数模板。
3. 大批量性能风险
   - 应对：流式渲染、分批提交、任务级监控。
4. 开源支持成本
   - 应对：日志可导出、最小复现模板、明确提单规范。

## 13. 后续扩展（MVP 之后）

1. 增加原生命令后端（ZPL/TSPL）提升速度与精度。
2. 增加数据源插件（数据库、HTTP API）。
3. 模板市场与团队共享（可选云化路径）。
4. 多平台支持（macOS/Linux）。
